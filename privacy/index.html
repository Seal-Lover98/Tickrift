PRIVACY

Privacy without unnecessary tracking.

The launch version keeps the simulator local and avoids analytics or advertising trackers.

Privacy at a glance

Tickrift is designed to work without user accounts. The launch version does not include Google Analytics, advertising trackers, social-media pixels or a marketing cookie banner.

Stored on your deviceYour simulation state

Virtual cash, positions, holdings, settings, watchlists and journal entries are stored in your browser so the simulator can remember your session.

Not sent as an accountNo Tickrift profile

Tickrift does not create a server-side account from your simulator state and does not ask for your name, email or payment details in this version.

Local browser storage

Tickrift uses browser storage for the features you explicitly use: keeping your paper account, settings and journal available when you return. Clearing site data in your browser removes that locally stored simulation state.

The site does not use that local state to build an advertising profile.

Network requests

When a licensed market-data feed is enabled, the browser requests market information from Tickrift's own API endpoint. The upstream provider key stays on the server and is not exposed in the browser.

Like most hosting and API infrastructure, the hosting provider and market-data provider may process ordinary technical information needed to deliver requests, such as IP address, timestamps and request metadata, under their own infrastructure and policies.

Changes

If Tickrift later adds accounts, payments, analytics or advertising, this page should be updated before those features go live. Features that require additional consent should not be enabled silently.
