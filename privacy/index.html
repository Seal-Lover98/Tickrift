PRIVACY

Privacy on Tickrift

Tickrift keeps the simulator functional without analytics. Google Analytics is optional and is loaded only after you choose to allow analytics.

Local simulator data

The website uses browser storage to remember virtual cash, positions, holdings, pending paper orders, watchlists and settings. Clearing site data or resetting the simulator removes that local state.

Shared order-flow data

If the optional global-flow backend is enabled, a filled paper order can send only the simulated instrument, buy/sell direction, paper notional and a random order identifier to the shared market endpoint. The feature does not require a real brokerage account or payment information.

Optional Google Analytics

Tickrift can use Google Analytics (measurement ID G-PK72BHMES7) to understand site usage, such as page visits and feature interactions. Analytics is optional and is not loaded until you allow it through the consent prompt. You can change your choice using the Analytics settings link. Hosting providers may still process standard technical request data such as IP addresses and server logs under their own infrastructure policies.
