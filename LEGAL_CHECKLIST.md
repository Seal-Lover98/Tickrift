# Tickrift launch checklist

This is a practical product checklist, not legal advice.

- [x] The product is explicitly labelled as a simulation.
- [x] No deposits, withdrawals, brokerage credentials or real order execution.
- [x] Virtual funds have no cash value.
- [x] Market data is labelled MARKET / DELAYED / SIMULATED.
- [x] No personalized real-money buy/sell recommendations are generated.
- [x] Privacy page is included.
- [x] Terms page is included.
- [x] Data Sources page is included.
- [x] No analytics or ad trackers in the launch build.
- [x] Simulator state stays in browser local storage; no account database in this version.
- [x] Market-data keys stay server-side.
- [ ] Before monetization, confirm the market-data provider plan and exchange display/redistribution rights.
- [ ] Before adding payments, accounts, analytics or advertising, update privacy/terms and add any consent flow that becomes necessary.
- [ ] Add a real support/contact method before accepting payments.
