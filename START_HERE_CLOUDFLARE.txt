TICKRIFT — CLOUDFLARE SETUP

1. GitHub: upload the contents of this folder so index.html is in the repository root. Commit to main.
2. Cloudflare Dashboard -> Workers & Pages -> Tickrift -> Deployments. Wait for the new deployment to say Success.
3. Cloudflare -> D1 SQL database -> Create database. Name: tickrift-market. If Data location/jurisdiction is offered, EU is suitable for an EU-based project.
4. Open tickrift-market -> Console and run the full schema.sql from this package. This creates market_impact, processed_orders and leaderboard_players.
5. Cloudflare -> Workers & Pages -> Tickrift -> Settings -> Bindings -> Add -> D1 database bindings.
6. Variable name MUST be MARKET_DB. Select tickrift-market. Save.
7. Go to Deployments and redeploy the latest GitHub commit. The binding only takes effect after redeploy.
8. Open https://YOUR-DOMAIN/api/market?symbols=NVDA . Look for globalFlow:true.
9. Open https://YOUR-DOMAIN/api/leaderboard . Before D1 is connected it will fail; after binding it should return JSON with rows.
10. Test Tickrift: Learn, Leaderboard, NVDA chart, timeframe buttons, Trade/Invest, open/close a paper position.
