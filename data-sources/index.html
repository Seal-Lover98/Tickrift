How Tickrift's shared simulated market works

Tickrift distinguishes between synthetic prices and any future external market-data feed. The current shared-market engine is designed so that visitors can see the same simulated base price at the same time.

Shared synthetic prices

The default engine derives prices from UTC time, instrument-specific volatility settings and deterministic noise. It does not need your browser to remain open. This makes the market continue moving between visits and avoids giving every visitor a completely different random chart.

Global player-flow effect

When the optional Cloudflare D1 backend is enabled, filled paper orders can contribute a very small signed pressure value to an instrument. The pressure decays over several hours. The base market still comes from the clock; the database only stores the temporary crowd effect.

Not real exchange data

A synthetic price should never be confused with a real share, fund, index or crypto quote. Tickrift labels the default feed as a simulation. If a real data provider is added later, its licensing and display requirements should be reviewed before public deployment.
